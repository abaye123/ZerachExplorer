## מה חדש בגרסה 2.0.0

- **עיצוב חדש** בסגנון Windows 11, תצוגת אריחים, שורת נתיב, חיפוש, מיון ותצוגה מקדימה.
- **פעולות קבצים:** העתקה, גזירה והדבקה (גם מול סייר Windows), תיקייה חדשה, טיפול בהתנגשויות, סל מיחזור.
- **כונני USB:** הוצאה בטוחה, רענון אוטומטי, והצעה לפתוח כונן שחובר (כבוי כברירת מחדל).
- **מסך ניהול:** פרופילי עמדה, הרשאות, סיומות, חסימת כוננים, מצב קיוסק ויציאה בסיסמה.
- **ייבוא וייצוא הגדרות** להגדרה מהירה של מחשבים רבים.
- **חלון התקדמות** עם קצב, השהיה וביטול.
- **תיקון:** כונן אחד שאינו מוכן כבר לא מונע את הצגת שאר הכוננים.
- **יומן פעולות** עם מחיקה אוטומטית לפי ימים ונפח.
- **אין צורך להתקין ‎.NET.**

### חשוב לדעת בשדרוג

- אין סיסמת ברירת מחדל. הסיסמה נקבעת בכניסה הראשונה להגדרות, ושמירת הגדרות דורשת אישור מנהל Windows.
- בכונן ללא סל מיחזור המחיקה סופית, אחרי אזהרה.

### איזה קובץ להוריד

- `ZerachExplorer_setup.exe` - מתקין, מומלץ לעמדות ציבוריות.
- `ZerachExplorer_portable.exe` - קובץ אחד ללא התקנה.

[מדריך התקנה, הגדרה ושימוש](https://github.com/abaye123/ZerachExplorer/blob/main/docs/guide.he.md)

## What's new in 2.0.0

- **New Windows 11 style interface** with tiles, breadcrumbs, search, sorting and quick preview.
- **File operations:** copy, cut and paste (also with Windows Explorer), new folder, conflict handling, recycle bin.
- **USB drives:** safe eject, automatic refresh and an optional offer to open a connected drive.
- **Administration:** profiles, permissions, extensions, drive blocking, kiosk mode and password-protected exit.
- **Import and export of settings**, and a progress window with pause and cancel.
- **Fixed:** one drive that is not ready no longer hides all other drives.
- **Audit log** with automatic cleanup by age and size.
- **No .NET installation needed.**

[User guide](https://github.com/abaye123/ZerachExplorer/blob/main/docs/guide.en.md)

There is no default password: it is set on the first visit to the settings, and saving requires Windows administrator approval.
