## דרישות

- Windows 10 או 11, 64 סיביות.
- אין צורך להתקין ‎.NET.
- להתקנה ולשמירת הגדרות: אישור מנהל Windows.

## התקנה

### מתקין (מומלץ לעמדות ציבוריות)

1. מורידים את [`ZerachExplorer_setup.exe`](https://github.com/abaye123/ZerachExplorer/releases/latest/download/ZerachExplorer_setup.exe).
2. מפעילים, מאשרים את חלון Windows ועוקבים אחרי ההוראות.
3. המתקין משדרג גם גרסאות קודמות, בלי להסיר אותן קודם.

התוכנה חתומה בתעודה עצמית, ולכן Windows עשוי להציג אזהרת SmartScreen: **מידע נוסף** ואז **הפעל בכל זאת**. הורידו רק מהקישורים הרשמיים.

התקנה שקטה, לסקריפט:

```bat
ZerachExplorer_setup.exe /VERYSILENT /NORESTART
```

### קובץ נייד

[`ZerachExplorer_portable.exe`](https://github.com/abaye123/ZerachExplorer/releases/latest/download/ZerachExplorer_portable.exe) פועל ללא התקנה. הוא מחלץ ספריות לתיקייה זמנית של המשתמש, ולכן בעמדה ציבורית עדיף המתקין.

## הגדרה ראשונה

1. פותחים את ההגדרות: כפתור גלגל השיניים, או `Ctrl+Shift+A`.
2. קובעים סיסמת מנהל, לפחות 8 תווים. **אין סיסמת ברירת מחדל.**
3. מאשרים את חלון Windows.

כל שמירת הגדרות דורשת אישור מנהל Windows. אחרי 5 סיסמאות שגויות יש השהיה שמתארכת, עד 15 דקות.

**חשוב:** מומלץ לקבוע סיסמה מיד אחרי ההתקנה, ולהפעיל את העמדה במשתמש Windows רגיל ולא במנהל. ראו גם [SECURITY.md](../SECURITY.md).

## מסך הגדרות המנהל

| לשונית | מה מגדירים |
|---|---|
| פרופיל והרשאות | רגילה, קריאה בלבד, מבוקרת או מותאמת אישית, וכל הרשאה בנפרד |
| קיוסק וכונני USB | מסך מלא, יציאה רק בסיסמה, הצעה לפתוח USB שחובר. הכול כבוי כברירת מחדל |
| סוגי קבצים | הסיומות שמותר לפתוח ולהעתיק |
| תיקיות מאושרות | תיקיות שמוצגות במסך הבית. בפרופיל מבוקר רק הן נגישות |
| כוננים | חסימת כוננים נוספים |
| יומן | מספר ימים לשמירה ונפח מרבי |
| סיסמת מנהל | החלפת סיסמה |
| ייבוא וייצוא | העברת הגדרות למחשבים אחרים |

סוגי הקבצים המותרים כברירת מחדל: `doc`, `docx`, `xls`, `xlsx`, `pdf`, `txt`, `csv`, `one`, `onetoc2`. כל הקבצים מוצגים, אבל רק אלה נפתחים ומועתקים.

כונן המערכת וכונני "אוצר החכמה" חסומים תמיד, וגם תיקייה מאושרת אינה עוקפת זאת.

## העברת הגדרות למחשבים נוספים

### מתוך התוכנה

1. במחשב המוגדר: **הגדרות > ייבוא וייצוא > ייצוא לקובץ**.
2. במחשב החדש: **הגדרות > ייבוא וייצוא > ייבוא מקובץ**, ואז **שמירה**.

הסיסמה אינה נכללת בקובץ, אלא אם מפעילים את המתג. אם אין בקובץ סיסמה, הסיסמה של המחשב החדש נשמרת. קובץ שכולל סיסמה מכיל גיבוב בלבד, אבל יש לשמור עליו במקום בטוח.

### בסקריפט, למחשבים רבים

מריצים כמנהל:

```bat
ZerachExplorer_setup.exe /VERYSILENT /NORESTART
start /wait "" "%ProgramFiles%\ZerachExplorer\ZerachExplorer.exe" --import-settings "\\server\share\ZerachExplorer-settings.json"
echo %errorlevel%
```

| קוד | משמעות |
|---|---|
| 0 | ההגדרות יובאו |
| 2 | לא הורץ כמנהל |
| 3 | הקובץ חסר או אינו תקין |
| 4 | השמירה נכשלה |

כדי שגם הסיסמה תוגדר, מייצאים את הקובץ עם הסיסמה.

## שימוש

- **מסך הבית** מציג את הכוננים הזמינים ואת התיקיות המאושרות.
- **העתקה והעברה:** עם סייר Windows ובתוך התוכנה. פעולה ארוכה מציגה חלון עם אחוזים, קצב, השהיה וביטול.
- **קובץ קיים ביעד:** התוכנה שואלת אם להחליף, לדלג או לשמור את שניהם.
- **מחיקה:** לסל המיחזור. בכונן ללא סל מיחזור (USB, רשת) המחיקה **סופית**, ויש אזהרה לפניה.
- **הוצאת USB:** לחיצה ימנית על הכונן ואז **הוצאה בטוחה**.
- **בחירה:** גרירת מלבן, תיבות סימון, או `Ctrl` ו-`Shift`. התיבות ניתנות להסתרה ב**תצוגה > תיבות סימון לפריטים**.
- **תצוגה מקדימה:** `Alt+P`. מציגה טקסט ופרטי קובץ או תיקייה.
- **חיפוש:** מסנן את התיקייה הנוכחית בלבד, ולא תיקיות משנה.

## הסתרת כונן

כונן נחסם אם מתקיים אחד מאלה:

- סומן בלשונית **כוננים** בהגדרות.
- יש בשורש שלו קובץ בשם `otzar.exe` (גם ריק) או תיקייה בשם `Otzar`.
- שם הכונן כולל `Otzar` או "אוצר החוכמה".

## פתרון בעיות

- **הכונן אינו מופיע:** ודאו שאינו חסום בהגדרות, שאין בו `otzar.exe` או תיקיית `Otzar`, ושסייר Windows רואה אותו.
- **קובץ אינו נפתח:** אם הופיעה הודעה, הסיומת אינה מאושרת. אם הקובץ נפתח ונסגר, תוכנת ההגנה של העמדה כנראה חוסמת את Word או את קורא ה-PDF, ויש לאשר אותם שם.
- **"ההגדרות נעולות":** קובץ ההגדרות פגום או אינו שייך למנהל. קביעת סיסמה חדשה באישור מנהל Windows מאפסת אותו.
- **שכחתי את הסיסמה:** מנהל Windows מוחק את `C:\ProgramData\ZerachExplorer\config.json`, וקובעים סיסמה מחדש. גם ההגדרות מתאפסות.
- **שגיאה בלתי צפויה:** הפרטים ב-`%LocalAppData%\ZerachExplorer\logs`.

## מיקומי קבצים והסרה

| מה | היכן |
|---|---|
| תוכנה | `C:\Program Files\ZerachExplorer` |
| הגדרות מנהל | `C:\ProgramData\ZerachExplorer\config.json` |
| יומן והעדפות תצוגה | `%LocalAppData%\ZerachExplorer`, לכל משתמש |

הסרה דרך הגדרות Windows. ההגדרות והיומנים נשארים, ואפשר למחוק אותם ידנית.
